## 1. Governance Principles & Strict Boundary Constraints

1. **Constitutional Mandate**: Per Constitution Principle I, immutable `String` references are strictly prohibited for application-owned secrets, and are permitted ONLY at audited platform input/rendering boundaries where mutable interfaces (`CharArray`, `ByteArray`, `ErasableCharBuffer`) do not exist.
2. **Absolute Exclusion**: **Cryptographic key material, seeds, normalization/serialization internals, cryptographic provider state, and diagnostic APIs NEVER qualify for the platform UI text exception.** Only genuine interactive platform input and rendering boundaries for user-managed non-seed secrets (e.g. vault item passwords in `BND-UI-001`, `BND-UI-002`) can be evaluated as permitted platform UI text exceptions under Constitution Principle I.
3. **Reviewer Provenance & Independence**: **Missing reviewer evidence remains missing; the consolidating author is not automatically the prior security reviewer.** Entries record original historical dispositions; consolidation does not confer fresh independent authorization.
4. **Findings vs. Permissions**: Unavoidable provider internals, native heap memory, JVM runtime copies, and diagnostic constraints are recorded strictly as **documented provider/runtime limitations or prohibited usages**, NEVER as approved platform UI text exemptions.
5. **Release & Isolation Controls**: Any platform string created at a permitted boundary MUST NOT become application state, cache, persistent data, or diagnostic output, and MUST be released immediately upon termination of the platform interaction.

## 3. Findings, Noncompliance & Residual Limitations Summary

1. **Non-Erasable Platform & Provider Copies**: Application-owned zeroing (`finally` blocks) guarantees that memory under Chimali's direct control is wiped immediately upon terminal paths. However, memory retained internally by Android platform APIs (Compose layout caches, ICU normalizer heap, JCA `KeyFactory`, Bouncy Castle `BCMLDSAPrivateKey`, system clipboard listeners) cannot be reached or erased by user-space code.
2. **Device Clipboard Acceptance**: While unit/host tests verify the 60-second timer and `IS_SENSITIVE` flag, end-to-end device confirmation remains tracked as an open follow-up (`FUP-SEC-001`).
3. **Live Source Audit Gate**: This register consolidates historical evidence from 2026-09-09 and 2026-10-14..16 reviews. Current release branch static and runtime audit is tracked under `FUP-SEC-001`.
4. **Boundary Distinction & No Inferred Exception**: Cryptographic material (BIP39 mnemonic, root PRK, derived private keys, intermediate factors), normalization buffers, cryptographic providers, and diagnostic APIs do NOT acquire platform UI text permissions. Only user interactive password input and clipboard transfer (`BND-UI-001`, `BND-UI-002`) are permitted platform UI text boundaries under Constitution Principle I. All other entries document non-erasable provider/runtime limitations or diagnostic redaction controls.
