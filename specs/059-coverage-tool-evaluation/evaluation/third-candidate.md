# Third Candidate Search

**Search scope**: Official Kotlin/Kover documentation and repository, official Gradle JaCoCo documentation, and targeted web searches for maintained JVM or Android alternatives with device-test collection. Search was bounded to primary documentation and project repositories; no exhaustive market survey was attempted.

**Result**: No third candidate selected. The IntelliJ coverage agent is related to Kover, and the reviewed official material did not establish it as a distinct, maintained complete Android host/device coverage tool for this workflow. Kover offline/CLI capability exists, but no supported complete device workflow was found. Historical Android instrumentation approaches and general JVM tools did not have enough current primary evidence for this workload.

**Disposition**: No credible additional candidate within the evidence boundary. This is a bounded search result, not a claim that no such tool exists. Candidate total: JaCoCo and Kover (two).

**Sources**: R4–R10.
