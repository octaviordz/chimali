- Each checklist item uses `- [ ] Tnnn [P?] [USn?]` and exact repository-relative file paths. Resolve paths from `D:\octav\source\repos\Chimali` when implementing.
- `[P]` permits concurrent work only after its prerequisites complete and only on the distinct files named by the task. It does not override the dependency section.
- New paths are intentional deliverables, not claims that those files already exist. Existing tests must be updated rather than duplicated where they serve the same purpose.
- Write story tests before behavior changes and record meaningful failing results, then passing results. Minimal compilable API declarations may be introduced to establish a behavioral failure; missing symbols, empty suites and fixture self-agreement are not passing or behavioral-red evidence.
