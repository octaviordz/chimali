# FIDO device and credential UI test lifecycles

`BluetoothHidTransportDisconnectDeviceTest` builds a synthetic credential summary, isolated wallet preference file and pending GetAssertion request to check that HID disconnect cancels the UI decision and invalidates the wallet session. Its teardown now clears input credential bytes, the credential summary RP owner and public-key encoding, CTAP channel/request/client-hash arrays, pending request owners, parser state and wallet session, then removes the isolated recovery directory. The encoded `CredentialId` is an immutable synthetic string and cannot be overwritten.

`FidoBleReconnectStressDeviceTest` exercises a synthetic CTAP corpus against physical BLE endpoints. It now clears intermediate request-construction arrays, per-batch copied requests and notifications, expected fragmented response frames, retained recorder copies and static request/response vectors. It logs only aggregate cycle, MTU, heap and GC metrics. FIDO KtLint and Android device-test compilation pass; the physical ASUS BLE run was not executed.

`CredentialListScreenTest` stops and clears each test-owned ViewModel, removes the Compose tree, erases synthetic credential text/credential-ID/AAGUID buffers and clears mock histories. `RegistrationFlowIntegrationTest` clears its Compose tree and erases the synthetic success credential and consent-state text owners. `RegistrationPromptScreenTest` and `AuthenticationPromptScreenTest` erase every synthetic sensitive-text state owner and dispose their Compose trees in `@After`; `CredentialDisplayNameTest` also disposes its composition. `AuthenticatorDashboardComponentsTest` removes its test composition after rendering fixed paired-device fixtures. These instrumentation tests now compile as part of `androidDeviceTest`; they were not run on-device.

`CredentialListScrollBenchmark` scrolls the app's passkey list but collects aggregate frame timings only; it does not read or export row values or clear application data. It must run under the isolated profile documented for the audit because the launched app may otherwise contain real credentials. The benchmark, Android profile provenance, renderer lifetime and artifact behavior remain unverified.

`NordicBleLegacyAdvertisingDeviceTest` uses a fixed service UUID and advertising lifecycle without credential/request data. `FidoBleLifecycleDeviceTest` uses a fake transport and fixed service-state counters. Both have file-specific no-relevant-secret dispositions. No device execution is claimed for these source assessments.
